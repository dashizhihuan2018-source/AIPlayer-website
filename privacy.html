这个网站做什么？

仅提供产品说明、教程、版本信息及 GitHub 下载链接。无登录、无广告、无分析 SDK、无远端字体请求，不读取媒体库，不要求提交影片或模型密钥；页面脚本只用于复制校验值。

站点由 GitHub Pages 及既有腾讯云静态镜像提供，浏览器访问时 GitHub 可能按其政策记录 IP 等请求信息。点击 GitHub 下载或源码链接将访问第三方平台，受其隐私政策约束。GitHub 隐私声明。

哪些数据留在本机？

配置、随机认证、观看记录、WebKit 数据及工具成果保存在当前 Mac。安装包不内置你的媒体、账号或历史；更新不主动删除用户设置。

  • 截图、GIF、海报：图片/AIPlayer/ 下的对应文件夹。
  • 导出视频：影片/AIPlayer/Clips/。
  • 已看视频包：本会话内存，回看上限 512 MiB、前向上限 128 MiB；不含解码器和应用内存。
  • 海报画面：最多 6 张内存截图，每张最长边 1200 像素；用户点击生成后才保存海报 PNG。
  • 切片源或退出释放上述内存缓存，超限淘汰；不是永久离线库。

桌面本地服务仅监听回环地址。随机认证不等于同一 macOS 用户下各进程之间的安全隔离。诊断快照可能包含当前播放内容，分享前必须自行审查。

什么时候会联网？

影视搜索、推荐、封面、来源订阅、在线视频播放和下载会向所选第三方服务发出请求，对方可能看到 IP、搜索词或资源请求。因此它不是全离线或匿名播放器。

「发布为链接」会主动上传来源列表到外部服务。不要把私人订阅、含密钥 URL、账号或密码放进去。22 个初始来源来自上游历史公开列表，不代表内容获得许可或服务始终可用。

AI、费用与未完成能力

AI 是品牌名称。当前版本未集成模型服务，无默认模型密钥、云登录或语义剧情分析。海报推荐是本地模板；本机文字识别不代表 AI 剧情理解。本版不会自动将本地影片发送给模型。

软件可免费获取，本站提供 GitHub Pages 与既有腾讯云静态镜像，没有收费结算。第三方网络、来源服务可能有独立条件或费用；本产品不提供其付费权益。未来如接入可选模型 API，需另行说明发送内容、提供商及按量费用，当前没有可用的云 AI 计费功能或“永久免费 AI”承诺。

投屏、字幕烧录、云账号、语义 AI 分析不属于本版已完成功能。未知时长直播不支持海报。真实第三方片源、所有格式与机器、长期缓存淘汰不保证已全部验证。
